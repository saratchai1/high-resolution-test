# high-resolution-test

Sentinel-2 monthly cloud-masked imagery and LDSR-S2 4x super-resolution experiment for plot 13-STC (Rayong, Thailand).

This repository is intentionally reproducible: imagery is fetched from real Sentinel-2 L2A STAC/COG assets and super-resolved with OpenSR/LDSR-S2. No generated satellite imagery is used.
